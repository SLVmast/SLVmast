## About
I'm a Junior QA Engineer focused on web application quality, functional testing, and software reliability.
My approach to testing is based on understanding requirements, exploring application behavior, identifying inconsistencies, and documenting defects clearly.
**What I work on**
- Functional and regression testing of web applications
- Smoke testing based on technical specifications
- Test case and checklist design
- Bug identification and structured reporting
- UI validation and cross-browser checks
- Analyzing application behavior using browser DevTools
**My QA philosophy**
> Don't just check whether something works. Understand how it can fail.
